# Manual de Instalação e Configuração

Este manual descreve os passos necessários para configurar o ambiente de desenvolvimento e executar o **sep-api** localmente.

## 1. Requisitos do Sistema
- Runtime correspondente à stack **Java**.
- Gerenciador de dependências correspondente (Gradle build.gradle, Docker Config).
- Acesso à internet para download de pacotes.

## 2. Instalação de Pacotes
Execute no terminal da raiz do projeto:
```bash
# Para Python
pip install -r requirements.txt
# Para NodeJS
npm install
```
